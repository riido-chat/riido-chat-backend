## 객관적 평가

### 강점

- 사용자 시나리오형 표현에서도 정답 문서 회수율이 안정적이다.
- 가능 여부, 설정 위치, 상태 전이, 상속 규칙 같은 세부 정책을 짧고 직접적으로 답한다.
- 실제 계정 상태와 장애 원인을 이용가이드의 일반 설명으로 대신하지 않는다.
- 완료 답변 전부가 검증된 원본 URL Citation을 포함한다.

### 남은 위험

- 문항별 1회 실행이라 생성 모델의 반복 변동성은 측정하지 않았다.
- 모두 단일턴이어서 FOLLOW_UP/NEW_TOPIC 분류와 Query Rewrite 품질은 이번 점수에 포함되지 않는다.
- 질문은 현재 문서를 보고 사람이 설계한 합성 평가셋이다. 실제 고객의 오타, 장문 상황 설명, 복합 의도 분포와 완전히 같지는 않다.
- 자동 채점은 의미 기반 LLM judge가 아니라 상태·핵심 문자열·Citation 문서 검사다. 이를 보완하기 위해 이번에는 완료 답변 40개를 수동으로 원문 대조했지만, 대규모 회귀 평가에서는 별도 의미 채점 체계가 필요하다.
- 정확도와 별개로 완료 답변 평균 5.17초는 개선 가치가 있다.
