# 시스템 버전 기록

모델, 프롬프트, 검색, 데이터 변경을 평가 기록과 연결하기 위한 전역 버전(`SYSTEM_VERSION`) 기록이다.
버전 기록은 필수이고 평가는 필요할 때만 진행한다. 평가하지 않은 버전은 "미평가"로 적고 수치로 인용하지 않는다.
버전 간 성능 비교는 평가 기록이 있는 버전끼리만 한다.

## 버전 규칙

| 구분 | 올리는 경우 |
| --- | --- |
| MAJOR | 모델 교체(임베딩 포함), 파이프라인 구조 변경(단계 추가나 제거 등) |
| MINOR | 프롬프트 판, 문턱값, 검색 파라미터, 정본과 데이터 변경, 재색인 |
| PATCH | 응답 동작이 바뀌지 않는 수정 |

- 재색인, DB 에서의 정본 승인처럼 PR 을 거치지 않는 변경도 MINOR 로 올리고 이 표에 수동으로 기록한다.
- CI 는 동작 관련 파일이 바뀐 PR 에서 버전 상수 갱신과 이 표의 행을 확인한다.

## 바뀐 단계 표기

`재작성` / `판별` / `검색` / `생성` / `구조` / `데이터` / `없음` 중에서 고른다. 여러 단계면 쉼표로 나열한다.
최초 행처럼 특정 단계 변경이 아닌 기준점은 `기준선` 으로 적는다.
