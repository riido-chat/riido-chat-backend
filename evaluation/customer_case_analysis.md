# 고객 상담 평가 자료 안내

기존 공개 고객 상담 후보와 분류 자료는 동일한 원본 HTML을 재편성한 후속 골든셋으로 대체되었습니다. 공개 저장소에서 고객 상담 원문이 포함된 JSON과 사례 분석 내용을 제거했습니다.

평가 항목의 정본, 원본 동결 정보, 라벨 연결 및 재구성 근거는 비공개 골든셋의 README, 스키마와 manifest를 확인하세요. 골든셋 1.0.0은 이 정리 과정에서 변경하지 않습니다.

기존 멀티턴 평가 도구의 기본 자료는 별도의 평가셋이므로 기본 경로는 유지합니다. 후속 골든셋의 전체 실행 도구와 Git 이력에 남은 원문의 정리는 별도 작업입니다.
