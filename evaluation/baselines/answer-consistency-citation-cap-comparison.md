  P1 baseline의 해당 턴과 일치했다.

  변동은 남아 있다. 20/20은 기존 수용 기준 통과이며 전 문장의 품질 보장은 아니다.

## 추가 질문과 최대 출처

| 질문 | 반복 결과 | 최종 고유 출처 |
| --- | --- | --- |
| CP01 스프린트 위치·기간·시작 요일·미리 생성·자동화 역할 | 5/5 정상 완료 | 매번 5개 |
| CP02 슬랙 기능·연결 절차·알림·비공개 채널·댓글 | 5/5 정상 완료 | 매번 4개 |
| CP03 작업 계층·속성·관계도·백로그 전환·스프린트 역할 | 5/5 근거 부족 보류 | 0개 |

- **구조상 한 답변의 최대 고유 Citation은 5개이고, 실제 관측 최대도 5개다.**
  후보 Source가 최대 5개이며, 전달받지 않은 Source는 인용할 수 없다.
- CP01의 5개는 스프린트 페이지의 서로 다른 Section 4개와 자동화 페이지의 Section 1개다.
  즉 원본 페이지는 2개, Citation은 5개다. 반복 marker는 출처 개수에 중복 계산하지 않는다.
- CP01의 4회차만 자동 키워드 평가에서 실패했다. `현재 스프린트` 대신
  `기존 스프린트`라고 썼지만, 설정 요일까지 유지 후 다음 스프린트가 시작된다고 설명했다.
  수동 검토상 이 실패는 해당 내용 누락이 아닌 표현 차이다. 원본 채점 결과는 수정하지 않았다.
- CP03은 모든 회차에서 Top-5에 스프린트 역할의 근거가 없었다. 따라서 문서 전체로는
  답할 수 있다는 기대와 이번 검색으로 제공한 근거가 달랐다. 주어진 근거에 한정하면
  보류는 타당하며, 개수 제한이나 인용 검증 실패가 아니다.
- 추가 질문의 자동 판정은 9/15다. 이를 모두 생성 오류로 세면 안 된다.
- 추가 질문의 정상 답변 10건은 인용 검증을 통과했고 응답과 DB의 출처 수가 일치했다.
  검증 재생성은 0회였다. FE 표시와 배포 환경은 확인하지 않았다.
